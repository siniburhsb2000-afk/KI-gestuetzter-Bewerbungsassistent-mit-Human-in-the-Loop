# Bewerbungen (lokal)

Arbeitsordner für einzelne Bewerbungen, z. B. `bewerbungen/2026-11_firma-stelle/`:

- `stellenanzeige.md`
- `anschreiben_v1.md`, `anschreiben_v2.md` …
- `analyse.json`: Ergebnis aus `prompts/anschreiben_analyse.md`

Persönliche Inhalte werden per `.gitignore` **nicht** committet. Nur diese README liegt im Repo.
